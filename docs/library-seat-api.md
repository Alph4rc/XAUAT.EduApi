# 图书馆座位查询

以下接口返回 EduApi 的标准响应，`data` 保留图书馆上游 JSON（包括上游的 `code` 和 `data`），以便使用上游座位坐标、标签及状态字段。日期格式为 `yyyy-MM-dd`，不填时使用学校当地日期；上游查询时段为学校当前时刻至一小时后，跨午夜时截止 23:59。

- `GET /v1/library/rooms?date=2026-11-16`：查询区域及空位数。上游默认第 1 页、最多 100 条。
- `GET /v1/library/rooms/3/seats?date=2026-11-16`：查询指定区域的座位。区域 ID 来自区域列表，时间段参数沿用原服务的 `segment=1`。
- `GET /v1/library/bookings?page=1&pageSize=10`：查询个人座位预约记录，携带请求头 `X-Library-Token: <图书馆 JWT>`。每页最多 200 条。该 JWT 来自图书馆登录，不是教务 Cookie，也不含 `bearer` 前缀；本接口目前不负责获取 JWT。

公开查询的成功结果在单个服务实例内按日期和区域缓存 20 秒；失败不缓存。个人预约请求不会缓存，也不会写入数据库。图书馆认证过期返回 401，上游不可用返回 502。
